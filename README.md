# ZoeDepth NYU+KITTI metric depth estimation pipeline

DIMER inference wrapper for **ZoeDepth fine-tuned on NYU Depth v2 and KITTI** (`Intel/zoedepth-nyu-kitti`), Intel Labs' ~345M-parameter monocular depth model (a BEiT-large DPT encoder–decoder with two metric bin heads — indoor 0.001–10 m and outdoor 0.001–80 m — picked per image by a latent domain classifier) that turns one RGB image into a depth map **in metres** — pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot. The pipeline accepts one image and an optional flip-augmentation flag, returns a float32 depth array at the input resolution with its minimum, median and maximum, and ships `abs_rel` and `delta1` for callers who bring a metric reference; it attaches no confidence and produces metres for any input.

## Upstream alignment

## Quick start

```python
import numpy as np
from PIL import Image
from zoedepth_metric_depth_pipeline import ZoeDepthMetricPipeline, abs_rel, delta1

pipe = ZoeDepthMetricPipeline.from_pretrained()        # stages + verifies weights/zoedepth-nyu-kitti first
result = pipe.predict(Image.open("room.jpg"))          # or flip_augmentation=True for the upstream TTA setting
depth = result["depth"]                                # float32 (H, W) in metres; larger = farther
print(result["depth_min"], result["depth_median"], result["depth_max"])

# score against a metric reference you captured (metres, same H x W; no alignment is applied)
reference = np.load("room_depth_m.npy")
print(abs_rel(depth, reference), delta1(depth, reference))
```

Install into a Python 3.12 environment that already holds the pinned dependencies with `pip install -e . --no-deps`; run `pytest -q -o addopts= tests` for the offline test suite (no weights needed). On a fresh clone the manifest is committed but the weights are not: `ZoeDepthMetricPipeline.from_pretrained(allow_download=True)` fetches exactly the missing manifest-listed files at the pinned revision, then verifies them.

## Weights layout

```
weights/zoedepth-nyu-kitti/
  dimer-base-manifest.json   # modelId, revision, per-file bytes + SHA-256 (4 files)
  config.json                # ZoeDepthForDepthEstimation: BEiT-large backbone, NYU 0.001-10 m + KITTI 0.001-80 m bin heads
  preprocessor_config.json   # ZoeDepthImageProcessor: fit 384x512 keeping aspect ratio, multiples of 32, pad, mean/std 0.5
  model.safetensors          # git-ignored, 1,380,374,404 bytes
  README.md
```

No `pytorch_model.bin` exists upstream at this revision; SafeTensors is the only weight file.

## Input ceilings and request parameters

`MIN_IMAGE_SIDE = 32`, `MAX_IMAGE_SIDE = 4096`, `MAX_ASPECT_RATIO = 4.0`; `flip_augmentation` (bool, default `FLIP_AUGMENTATION = False`; two passes averaged when true); output `DEPTH_KIND = "metric"` in `DEPTH_UNIT = "metres"`, `DEPTH_RANGES_M` per head; `DELTA_THRESHOLD = 1.25` for `delta1`. See `MODEL_CARD.md` for what the metres are and are not, the recorded blank-image behaviour, and the measured CPU timings.
